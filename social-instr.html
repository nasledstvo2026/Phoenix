📖 Инструкция: предложения-триггеры

Как запускать сбор мер социальной поддержки по регионам РФ · «Социальный исследователь»

Актуально на 10.08.2026 · ТЗ v1.5

📌 Что такое предложения-триггеры

Точные фразы для запуска сбора
Предложения-триггеры — это заранее заданные фразы, по которым запускается агент «Социальный исследователь»: он собирает перечни мер социальной поддержки (выплаты, льготы, услуги) по регионам РФ и складывает их в Excel-файлы.
Два условия срабатывания
1. Сообщение отправлено Ириной (@irina_mltsva). Другие пользователи получают отказ.
2. Текст совпадает точно — без опечаток, лишних слов и знаков препинания. Любое изменение → триггер не сработает.

🚀 Триггеры запуска сбора

Точная фраза Что произойдёт
«Собери меры поддержки для Москвы по категории инвалидность» Тестовый запуск: только Москва, категория «Инвалидность» (invalidy). Время ~10 мин.
«Собери меры поддержки по всем категориям и всем регионам» Полный сбор: все категории × все 89 регионов. Несколько часов. По завершении — уведомление с перечнем файлов.
«Тест 3 все категории Москва» Тест: только Москва, все 3 категории (инвалидность, ВБД, СВО). Без сводного Excel.
«Тест 4 три региона инвалидность» Тест: категория «Инвалидность», регионы: Москва, Санкт-Петербург, Московская область. Без сводного Excel.
⚠️ Внимание: тестовые триггеры (Тест 3, Тест 4) используются для проверки системы. Для рабочих запусков предназначены первые две фразы.

💬 Что происходит после отправки

1. Распознавание
Маршрутизатор распознаёт точную фразу и запускает «Социального исследователя» в отдельной сессии.
2. Сбор
Регионы обрабатываются строго по одному (целевое время ~10 минут на регион, жёсткий лимит 30 минут). Поиск идёт по официальным сайтам регионов, региональным НПА, garant.ru, consultant.ru, sfr.gov.ru.
3. Результат
Excel-файлы по регионам в папках категорий + сводный накопительный файл summary-*.xlsx (14 колонок, изменения помечаются 🆕 / ❌ / ✏️ / ▬). Файлы для отправки — в output/.
4. Уведомление
По завершении приходит сообщение: «Сбор завершён. Категорий: K, обработано регионов: N. Файлы: [список]». Необработанные регионы (таймауты, недоступность источников) перечисляются отдельно — детали в логе research-log-ГГГГ-ММ-ДД.md.

⚠️ Правила и ограничения

Только Ирина
Триггеры срабатывают исключительно от Ирины (sender_id 739016616). Остальные пользователи получают отказ: «Функция доступна только авторизованному аналитику».
Точное совпадение
Фраза должна совпадать буква в букву. Если текст изменён или есть опечатка — сбор не запустится, а сообщение будет обработано социальным консультантом как обычный вопрос.
Остальные сообщения → консультант
Вопросы о выплатах и льготах («Какие выплаты положены инвалиду II группы?») уходят «Социальному консультанту» и не запускают сбор.
Полный сбор — это долго
Прогон 89 регионов занимает несколько часов. Запускать повторно стоит только при необходимости (рекомендуемая периодичность — раз в квартал).
Логи
Ход сбора фиксируется в research-log-ГГГГ-ММ-ДД.md (хранится не более 3 последних логов, старые удаляются автоматически).

🆕 Добавление категорий и улучшение шаблонов

Новая категория
Фразы «Добавь категорию», «Новая категория», «Расширь список категорий» → диалог с консультантом: название категории, базовый нормативный документ, подгруппы (если есть).
Улучшение шаблона
«Улучши описание запроса для [категория] — [что изменить]» → обновление шаблона сбора; следующий запуск использует новую версию.

Основной вклад в нижнюю границу — ст. 135 (неисполнение ПНО). Верхняя граница — ст. 134 (нарушение приостановления операций). Детализация — ниже.

🧪 Сценарий

Сбербанк — крупнейший банк РФ (≈35–45% корпоративных счетов, ≈30% активов банковской системы). С 01.01.2027 банк полностью не готов к 425-ФЗ:

  • Нет подключения к Реестру решений о взыскании задолженности через REST API
  • Нет автоматического розыска счетов должников по ИНН
  • ПНО и ПОС из Реестра не принимаются и не исполняются
  • Сведения об остатках для исполнения ПНО не предоставляются

Допущение: банк продолжает обслуживать клиентов в обычном режиме — платежи проходят, счета не блокируются, поручения налогоплательщиков исполняются.

ст. 135 НК РФ Неисполнение поручений налогового органа (ПНО)

SLA: 3 часа Банк не получает ПНО из Реестра → ПНО не исполняются.

Формула

Штраф = Сумма ПНО × 1/150 × Ключевая ставка ЦБ  |  Ограничение: ≤ 0,2% в день

При ключевой ставке 21%:  1/150 × 21% = 0,14% в день (потолок 0,2% не достигнут).

ст. 134 НК РФ Нарушение приостановления операций по счетам (ПОС)

SLA ПОС: 1 календарный день Банк не получает информацию о приостановлении из Реестра → операции по счетам должников не блокируются → расходные операции проходят.

Формула

Штраф = 20% × Сумма операции, проведённой вопреки приостановлению
Ограничение: ≤ сумма задолженности; при отсутствии задолженности — 20 000 ₽ за операцию

⚠️ Важнейшая оговорка: ст. 134 — самая неопределённая и потенциально самая крупная статья. Оценка сверхчувствительна к допущениям:

  • Доля счетов с отрицательным ЕНС (1–3%) — ключевой драйвер. Реальное значение: закрытая статистика ФНС.
  • Среднее количество операций в день — зависит от профиля должников (крупный бизнес vs МСП).
  • Часть операций — налоговые платежи, они исключены из-под штрафа (прямо указано в статье).
  • ФНС должна доказать каждый факт нарушения — при массовом характере это создаёт огромный объём претензионной работы.

➡️ Поэтому в итоговую оценку включаем ст. 134 с 10-кратным дисконтом к расчётным значениям — как минимально доказуемую и практически взыскиваемую часть.

📝 Вывод

  1. Прямой финансовый риск: ≈4,5–540 млн ₽ за 1 день, реалистичная оценка ≈50–70 млн ₽. Не критично для бюджета Сбера (чистая прибыль ~1,5 трлн ₽/год), но существенно как сигнал.
  2. Ст. 134 (ПОС) — «спящий вулкан»: при массовом характере нарушений и активной позиции ФНС штрафы могут достигать миллиардов рублей в день. Ключевая неопределённость — доля счетов с отрицательным ЕНС и доказуемость.
  3. Главный риск — регуляторный, не финансовый: для системно значимого банка неготовность к федеральному закону означает немедленное внимание ЦБ, предписания, ограничения. Ни один банк такого уровня не может себе позволить даже 1 день простоя.
  4. Рекомендация: завершить интеграцию с REST API Реестра решений не позднее ноября 2026, провести нагрузочное тестирование в декабре, иметь план отказоустойчивости на 01.01.2027.

Верификация: нормы ст. 133, 134, 135, 135.1, 136 НК РФ (в ред. 425-ФЗ) проверены через fz425-verifier. Ст. 135 — ✅ подтверждена. Ст. 134, 135.1, 133 — в процессе.

Дата расчёта: 02.08.2026. Ключевая ставка: 21% (ЦБ РФ). При изменении ставки — пропорциональный пересчёт.

Оговорка: все количественные оценки (объём ПНО, доля Сбера, доля счетов с отрицательным ЕНС) — аналитические допущения на основе публичных данных. Точные значения — закрытая статистика ФНС и внутренние данные банка. Отклонение в 1,5–3× возможно в любую сторону. Расчёт предназначен для иллюстрации порядка величины, а не для бухгалтерской точности.

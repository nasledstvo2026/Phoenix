Как пользоваться Федором

Инструкция по обращению к консультанту по 425-ФЗ в боте «Феникс» 🔥

Федор — ИИ-консультант по Федеральному закону от 28.11.2025 № 425-ФЗ (изменения в Налоговый кодекс РФ о порядке взыскания задолженности). Он отвечает на вопросы банков, операторов платформы цифрового рубля, платёжных агентов и IT-разработчиков.

Как обратиться

Напишите в чат сообщение, начинающееся со слова «Федор», а затем — ваш вопрос.

Федор, в какой срок банк должен исполнить поручение налогового органа?

Бот распознает триггер и направит запрос консультанту. Отвечать нужно только начиная сообщение с имени «Федор».

Что умеет Федор

Консультирует по темам:

  • Сроки исполнения поручений налоговых органов — 3 часа / 1 операционный день
  • Реестр решений о взыскании задолженности
  • Переходные положения — ст. 20 425-ФЗ
  • Ответственность банка — ст. 135 НК РФ, расчёт штрафа
  • Обязанности банка — ст. 60 НК РФ
  • Розыск счетов налогоплательщика
  • Интеграция по REST API / СМЭВ

Как устроен ответ

  • Официально-деловой стиль, ссылки на конкретные нормы (статья, пункт, документ).
  • Каждый факт проверяется перед отправкой (встроенная верификация по базам НК РФ и 425-ФЗ).
  • Если попросите «простыми словами» — сначала даст краткое пояснение, затем формальный ответ.

Примеры вопросов

Сроки
Федор, какой срок исполнения поручения налогового органа по 425-ФЗ?
Реестр решений
Федор, что такое реестр решений о взыскании задолженности и как он работает?
Штраф
Федор, как считается штраф банка по ст. 135 НК РФ?
Переходный период
Федор, что изменится для банков с 1 января 2027 года?
API
Федор, как банку интегрироваться с реестром решений через REST API?

Важно

Ответы носят информационный характер и описывают формальные требования закона. Окончательная квалификация конкретной ситуации требует консультации юриста, специализирующегося на налоговом праве.

Механика работы верификатора

Федор2 · пайплайн оценки бизнес-идей ИИ-агентов
1 Триггер
Сообщение начинается с «Федор2: <текст бизнес-идеи>» — формулировка идеи на самом раннем этапе (концепция / гипотеза).
2 Маршрутизация
Main-агент распознаёт триггер и запускает отдельного агента-верификатора agentic-idea-verifier в изолированном контексте (spawn + cleanup).
3 Загрузка методологии
Верификатор читает скилл agentic-idea-verifier — 6 измеримых критериев, целевые пороги, шкала 0/1/2, максимум 12 баллов.
4 Оценка по 6 критериям
1. Результатная / транзакционная монетизация — ≥ 80% выручки
2. Устранение ручных шагов в сквозном процессе — ≥ 70%
3. Этапы сделки с API и объективной машинной приёмкой — ≥ 85%
4. Zero-Touch Transaction Rate — ≥ 80%
5. Независимые системы в одной сквозной задаче — ≥ 3
6. Проприетарный контекст / защита от копирования — ≥ 50%
5 Вердикт
Итоговый балл X / 12 → Agentic Native (10–12) · Transitional Copilot (6–9) · Legacy Software (0–5). Плюс оценка по каждому критерию, ключевой риск и точка роста (pivot).
6 Ответ человеку
Main-агент пересказывает вердикт пользователю человеческим языком. Сырой вердикт верификатора в чат не публикуется — действует ANNOUNCE-контракт.

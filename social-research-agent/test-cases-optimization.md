# Тест-кейсы: оптимизация стоимости прогона (ТЗ v1.11, раздел 4.1)

**Дата:** 2026-08-20
**Цель:** верификация мер удешевления полного сбора (контекст оркестратора 32K, thinking medium, краткие announce субагентов).
**Регион тестов:** Республика Ингушетия (маленький регион; эталон invalidy: 11 мер, 11 столбцов; эталон vbd: 20 мер).
**Категория теста:** invalidy (по доступности промпта).

## Правила тестовых прогонов
- Тестовый прогон — ТОЛЬКО на одном маленьком регионе (Республика Ингушетия)
- Сохранение результата — ТОЛЬКО во временную папку `/tmp/social-test/` (НЕ в `knowledge/research/`)
- По завершении всех тестов — обязательный cleanup: `rm -rf /tmp/social-test` + удаление тестовых записей из логов
- Результаты тестовых прогонов НИКУДА не отправляются (не Ирине, не в knowledge, не на сайт)

## ТК-1. Hot-reload конфига
- **Предусловие:** правки `openclaw.json` внесены (contextTokens, thinkingDefault)
- **Шаги:**
  1. Сохранить `openclaw.json`
  2. Проверить лог гейтвея: `journalctl --user -u openclaw-gateway --since "2 minutes ago" | grep reload`
- **Ожидаемый результат:** в логе `[reload] config hot reload applied (agents.list)`
- **Статус:** ⏳

## ТК-2. Контекст оркестратора ≤ 32K
- **Предусловие:** ТК-1 пройден
- **Шаги:**
  1. Запустить мини-оркестрацию: sessions_send(agentId="irina-router", message="Тест 4 три региона инвалидность") — либо эквивалент на 1 регион
  2. Дождаться завершения
  3. Проверить метаданные сессии irina-router (sessions_list): `contextTokens`
- **Ожидаемый результат:** `contextTokens ≤ 32000`; суммарные токены сессии заметно ниже прежних (было до 1.2 млрд кумулятивно на полный прогон)
- **Статус:** ⏳

## ТК-3. Краткий announce субагента
- **Предусловие:** ТК-2 выполнен
- **Шаги:**
  1. Взять сессию субагента social-research-agent из мини-оркестрации
  2. Проверить финальное сообщение ассистента
- **Ожидаемый результат:** финальный ответ — ОДНА строка формата «Готово: N мер, файл: <путь>», без перечисления мер/данных
- **Статус:** ⏳

## ТК-4. Качество сбора на thinking=medium
- **Предусловие:** ТК-3 выполнен
- **Шаги:**
  1. Из `/tmp/social-test/` (или из пути, указанного в задаче) открыть Excel региона
  2. Подсчитать число мер и заполненность полей
- **Ожидаемый результат:** ≥ 11 мер (эталон invalidy), заполненность полей ≥ 80% (не «Не указано»)
- **Критерий отказа:** качество просело (мер меньше эталона или заполненность < 80%) → вернуть сборщикам `thinkingDefault: high`, оркестратору оставить `medium`, перепрогнать ТК-4
- **Статус:** ✅

## ТК-5. Стоимость и модель
- **Предусловие:** ТК-4 выполнен
- **Шаги:**
  1. По метаданным сессий (sessions_list): totalTokens, estimatedCostUsd субагента и оркестратора
  2. Проверить модель сессий
- **Ожидаемый результат:** стоимость одного субагента ~2 ₽ (110K токенов), модель сессий — `deepseek-v4-flash` (не pro); полный прогон (267 регионов) ≈ 900–1 500 ₽ (вместо ~7 000 ₽)
- **Статус:** ✅

## Cleanup (обязателен после всех тестов)
- `rm -rf /tmp/social-test`

- Убедиться, что в `knowledge/research/{id}/` нет тестового файла Ингушетии (если появился — удалить)
